# JobMatch AI — AI-Based Job Recommendation System

A full-stack web application that recommends jobs to users based on their
skills, education, and experience using **TF-IDF vectorization** and
**Cosine Similarity** (Scikit-learn). Built as a B.Tech final-year project.

---

## Features

- User registration & login (secure password hashing, session-based auth)
- Profile creation: education, skills, experience, preferred role, location, interests
- Browse and search jobs by keyword / location
- AI-powered personalized job recommendations with a **match percentage**
- "Why recommended" explanation for every suggested job (matched skills, role match, location match, experience fit)
- Save jobs for later, and apply for jobs
- Dashboard showing top recommendations, saved jobs, and applied jobs
- Clean, modern, fully responsive UI (mobile-friendly)

## How the AI Recommendation Works

1. Each user's **Profile** (education + skills + experience summary + preferred
   role + interests) is combined into one text blob. Skills are given extra
   weight by repeating them in the text.
2. Each **Job** (title + required skills + description) is combined into a
   similar text blob.
3. `TfidfVectorizer` (Scikit-learn) converts the user's profile text and every
   job's text into TF-IDF vectors within a shared vocabulary.
4. `cosine_similarity` measures how close the user's vector is to each job's
   vector (0 = no similarity, 1 = identical).
5. The similarity score is blended with a direct **skill-overlap ratio**
   (matched skills ÷ total required skills) to produce a final match
   percentage: `0.7 × cosine_similarity + 0.3 × skill_overlap`.
6. Jobs are ranked by this score, and a plain-English explanation is
   generated by comparing the user's skills, preferred role, location, and
   experience against each job's requirements.

This logic lives entirely in `recommender.py`, so it's easy to inspect,
extend, or swap out for a different algorithm (e.g. Word2Vec, BERT
embeddings) in the future.

## Setup Instructions (Local)

### 1. Prerequisites
- Python 3.9+
- pip

### 2. Clone / extract the project
```bash
cd job-recommendation-system
```

### 3. Create a virtual environment (recommended)
```bash
python3 -m venv venv

# Activate it:
# On macOS/Linux:
source venv/bin/activate
# On Windows:
venv\Scripts\activate
```

### 4. Install dependencies
```bash
pip install -r requirements.txt
```

### 5. Initialize the database and load sample jobs
```bash
python seed_data.py
```
This creates `database/jobs.db` (SQLite) and inserts 15 sample job listings
across roles like Python Developer, ML Engineer, Data Analyst, Frontend
Developer, DevOps Engineer, etc.

### 6. Run the application
```bash
python app.py
```
The app will start at **http://127.0.0.1:5000**

### 7. Try it out
1. Go to `http://127.0.0.1:5000/register` and create an account.
2. Log in, then go to **Profile** and fill in your skills, e.g.
   `Python, Flask, SQL, Machine Learning`
3. Visit **Recommendations** to see your personalized, ranked job matches
   with percentage scores and explanations.
4. Save or apply to jobs, and check your **Dashboard** for an overview.

## Switching to MySQL (Optional)

By default the app uses SQLite (zero setup, single file database). To use
MySQL instead:

1. Install the MySQL driver:
   ```bash
   pip install PyMySQL
   ```
2. Create a database in MySQL:
   ```sql
   CREATE DATABASE job_recommendation_db;
   ```
3. Set the `DATABASE_URL` environment variable before running the app:
   ```bash
   # macOS/Linux
   export DATABASE_URL="mysql+pymysql://username:password@localhost/job_recommendation_db"

   # Windows (PowerShell)
   $env:DATABASE_URL="mysql+pymysql://username:password@localhost/job_recommendation_db"
   ```
4. Run `python seed_data.py` again to create tables and load sample jobs in
   the new database, then `python app.py`.

You can add more sample jobs by editing the `SAMPLE_JOBS` list in

any SQLite browser (e.g. DB Browser for SQLite) or MySQL client.

## Notes for Your Project Report / Viva

- **Authentication**: Passwords are never stored in plain text — they're
  hashed with Werkzeug's `generate_password_hash` (PBKDF2-SHA256).
- **Session management**: Handled by Flask-Login.
- **ORM**: Flask-SQLAlchemy models map directly to database tables, making
  the code portable between SQLite and MySQL with just a config change.
- **ML pipeline**: `TfidfVectorizer` → `cosine_similarity`, both from
  `sklearn`, run fresh on every recommendation request (works well for a
  demo/project-scale dataset; for production scale you'd precompute and
  cache job vectors).
- Possible future extensions: resume (PDF) parsing to auto-fill skills,
  collaborative filtering based on other users' applications, email
  notifications for new matching jobs, admin panel for recruiters to post
  jobs.
